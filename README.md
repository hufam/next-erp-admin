# NEXT ERP 시스템관리 V1
별도 GitHub Pages 저장소 `next-erp-admin`의 루트에 이 폴더의 내용물을 배치합니다. 기존 사용자 포털에 덮어쓰지 마십시오. 빌드 없이 정적 배포 가능합니다.

- 원본 포털 CSS 및 Supabase 공개 설정을 복사했습니다. common_v2는 제공 원본을 TypeScript에서 ES module JS로 변환하고 import 확장자만 조정했습니다. 기존 프로젝트 원본 수정 없음.
- 시스템 관리자 이메일 로그인, 회사 조회/등록/수정, 회사별 모듈 설정, 사원 조회/신규 계정 생성 지원.
- 시스템 관리자 세션은 별도 storageKey 사용. 유지보수 접속, 권한 변경/회수, 비밀번호 초기화, 기존 Auth 계정 복구는 미구현. 사용자 포털 로그인 변경 없음.
- 계정 생성은 실제 Auth 데이터를 생성합니다. 이메일 소유 확인 및 동의 후에만 실행. 연결 실패 시 재시도 전에 DB/Auth 상태 확인.
- 서버 RPC 및 Edge Function은 기존 배포본 사용. 브라우저 실제 연동 검증 전 일반 사용자 공개 금지.
- 테스트: 관리자 로그인 → 회사 목록 → 모듈 조회 → 사원 조회 → 승인된 테스트 계정 생성. 비관리자 로그인 거부 확인. 회사 ADMIN의 기존 모듈 설정 RPC 권한 및 RLS/퇴사자 세션 차단은 후속 보안 검증 필요.
